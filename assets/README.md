# Assets

| File | Use |
|---|---|
| `grocery-mcp.svg` | Source icon: a shopping basket with a shekel price tag, using no store logos |
| `grocery-mcp-256.png` | 256 × 256 PNG with transparent corners, under 10 KB, for ChatGPT's custom MCP server icon and similar uploads |

To regenerate the PNG after editing the SVG, render it at 256 × 256 with a transparent background, for example with headless Chrome. Then reduce it to a 256-color palette PNG, for example with Pillow's `quantize`, to stay under ChatGPT's 10 KB limit.
